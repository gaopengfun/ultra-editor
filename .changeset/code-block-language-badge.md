只读页的代码块右上角显示语言角标

编辑态的代码块一直有工具条,左上角的选择器明写着这块是什么语言;只读页把同一份 HTML
包进 `ue-content` 之后,这个信息就只剩 `<code>` 上那个 `language-` 类,对读者是不可见的
—— 一段 Rust 和一段 Go 在页面上长得一模一样。

角标取自 `<pre>` 上的 `data-language`,也就是 `renderHTML` 本来就会写出的那个属性,
不需要额外的标记或运行时。大写展示。

没有标语言的块不显示角标。`attr()` 读不到属性时返回的是空串而不是 `none`,伪元素照样
生成,单靠 padding 和背景就能画出一颗空药丸;而 `content.css` 是编辑态与只读态共用的
同一份样式,不收口的话每个正在编辑的代码块右上角都会多出这么一颗。
